# مرکز تخصصی زوج‌درمانی، مشاوره خیانت و بهبود روابط عاطفی مهناز خوینی (Zoojdarman)

این پروژه پلتفرم مدرن تحت وب زوج‌درمانی و مشاوره تخصصی روابط عاطفی تحت نظارت سرکار خانم **مهناز خوینی** (کارشناس ارشد روان‌شناسی بالینی، مسئول فنی کلینیک پیوند امن و عضو سازمان نظام روان‌شناسی با پروانه ۱۴۱۴۰۸۳) است که به فریم‌ورک **React** (همراه با Vite، TypeScript و Tailwind CSS) بازنویسی شده است.

---

## ویژگی‌ها و امکانات پلتفرم

- **هدر و ناوبری ریسپانسیو:** دسترسی سریع به بخش‌های درمانی، منوی دراور برای دستگاه‌های همراه و نمایش شماره پروانه رسمی نظام روان‌شناسی.
- **ویجت تشخیصی و تریاژ تعارضات رابطه:** ۴ سناریوی بالینی تعاملی (مشاجرات مکرر، شوک خیانت، سردی عاطفی، اختلافات پیش از ازدواج) همراه با پیام‌های آماده نوبت‌دهی در واتساپ.
- **خدمات تخصصی بالینی:** ۶ حوزه درمانی کامل همراه با صفحات اختصاصی، پروتکل‌های EFT و گاتمن، و پرسش‌وپاسخ‌های تخصصی.
- **فرآیند ۴ مرحله‌ای درمان:** تشریح گام‌به‌گام مراحل زوج‌درمانی استاندارد.
- **بانک مقالات و راهنما:** بیش از ۴۰ مقاله جامع بالینی با قابلیت فیلتر بر اساس موضوعات، جستجوی بلادرنگ، و مطالعه کامل مقاله همراه با چکیده طلایی، پرسش‌وپاسخ و ارجاعات مرتبط.
- **فرم رزرو و ارزیابی:** اتصال مستقیم به واتساپ کلینیک و اطلاعات تماس و ساعات کاری.
- **حریم خصوصی و محرمانگی:** تطابق کامل با استانداردهای نظام روان‌شناسی و سوگندنامه درمانی.

## راه‌اندازی و توسعه محلی

۱. نصب وابستگی‌ها:
```bash
npm install
```

۲. اجرای سرور توسعه (پورت ۳۰۰۰):
```bash
npm run dev
```

۳. ساخت نسخه بهینه‌سازی شده (Build):
```bash
npm run build
```
